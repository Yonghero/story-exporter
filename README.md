# 晚安故事生成器

一个简单的网页应用，用于创建和导出晚安故事图片。

## 功能特点

- 支持输入故事标题和内容
- 实时预览故事卡片效果
- 一键导出为高质量PNG图片
- 响应式设计，支持各种设备

## 开发技术

- Vue 3
- TypeScript
- Tailwind CSS
- html2canvas

## 本地开发

1. 安装依赖：
```bash
pnpm install
```

2. 启动开发服务器：
```bash
pnpm dev
```

3. 构建生产版本：
```bash
pnpm build
```

## 使用说明

1. 在左侧输入框中输入故事标题和内容
2. 右侧实时预览生成效果
3. 点击"导出图片"按钮下载故事卡片

## 注意事项

- 导出的图片为PNG格式，支持透明背景
- 图片分辨率已优化，适合社交媒体分享
